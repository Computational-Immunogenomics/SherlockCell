# SherlockCell  <img src="docs/images/SherlockCell_full.png" alt="SherlockCell logo" align="right" width="150">
`SherlockCell` is a pipeline for identifying malignant cells from single-cell RNA sequencing (scRNA-seq) data based on copy number variation (CNV) profiles and tumor heterogeneity features. It is built on [swiftCNV](https://github.com/Computational-Immunogenomics/SwiftCNV), a fast and scalable Python implementation of the original [InferCNV](https://github.com/broadinstitute/inferCNV/wiki) algorithm extended with additional features.
